Entry for the [make.fun](https://make.fun) competition **The Robot Vacuum's Funniest Excuse**: one line, at most 120 characters, in which a robot vacuum explains why it missed a spot.

## The line

> My sensors detected a sock, a cable, and my own will to live. I cleaned around all three.

(89 characters)

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed). Python standard library only — no third-party dependencies.
